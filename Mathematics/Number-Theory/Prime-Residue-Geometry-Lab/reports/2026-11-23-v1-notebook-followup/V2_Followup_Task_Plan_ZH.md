## 1. 研究目标

围绕前三个研究问题组织后续工作：

- **RQ1 数学结构：** 素数余数的二维复数投影具有什么可严格证明的性质？
- **RQ2 数论信息：** 控制模运算本身带来的信息后，投影能否揭示额外的素数与合数差异？
- **RQ3 极限行为：** 改变权重或时间尺度后，能否获得非恒定、稳定且可证明的几何极限？

初版定义为：

\[
\Phi_k(n)=\sum_{j=1}^k w_j e^{2\pi i(n\bmod p_j)/p_j}, \qquad
F_k(t)=\sum_{j=1}^k w_j e^{2\pi it/p_j}.
\]

其中 \(p_j\) 是前 \(k\) 个素数；二维坐标为复数的实部与虚部。

### P1 — 补全数学解释（RQ1）

- [ ] 写出 \(e^{2\pi i(n\bmod p)/p}=e^{2\pi in/p}\) 的证明。
- [ ] 推导有限求和 \(F_k(t)\) 的任意阶导数，说明其属于 \(C^\infty\)。
- [ ] 证明 \(M_k=\prod_{j=1}^k p_j\) 是一个周期；不得未经证明声称它总是最小周期。
- [ ] 解释 FFT 峰值与频率 \(1/p_j\) 的关系。
- [ ] 增加“二维投影的信息损失”说明：不同整数可能落在同一坐标。

**验收：** 每张基础图像都能对应一个已知结论、一个简短证明或一个明确的观察问题。

### P1 — 重建素数与合数对照实验（RQ2）

- [ ] 增加同余类基线：\(\Phi_k(n)\) 仅依赖于 \(n\bmod M_k\)。
- [ ] 展示反例：当 \(k=4\) 时，\(53\) 是素数、\(473=11\times43\) 是合数，但两者差 \(420=2M_k\)，故映射相同。
- [ ] 不只比较均值；可补充分布距离、类别不平衡和置信区间，但需说明对应统计假设。
- [ ] 引入按整数大小范围、模 \(M_k\) 同余类匹配的对照；分析简单随机标签置换的局限。
- [ ] 多个 \(N,k\) 与随机种子重复实验，报告未显著的结果，而非只展示漂亮的图。
- [ ] 将“模型是否能分类”与“几何投影是否含有超出同余类的新信息”明确区分。

**验收：** 不能只靠小素数筛选效果宣称发现素数新结构；任何差异均需与同余类基线比较。

### P1 — 搜索非平凡极限（RQ3）

- [ ] 保留原等权固定时间实验作为**反例基线**：对任意固定有界 \(t\) 区间，\(F_k(t)\to1\) 且一致收敛。
- [ ] 测试尺度变化，如 \(F_k(p_k t)\)、\(F_k(\sqrt{p_k}\,t)\)。
- [ ] 比较等权、按素数大小加权、随索引快速衰减的权重；明确各组归一化方式。
- [ ] 在固定公共区间、统一采样密度下比较 \(k\) 的变化，并绘制曲线距离。
- [ ] 区分“有限样本看上去收敛”和“证明一致收敛”；不能从数值图直接断言存在极限。

**验收：** 至少提出一个可证伪的新假设，给出支持与反例检查，不预先要求它成立。
