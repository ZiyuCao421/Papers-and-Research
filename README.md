# Papers-and-Research

## 中文

本仓库用于整理不同学科的论文与研究资料，包括我对相关概念提出的猜想与推导、借助 AI 工具开展的探索，以及少量围绕我的小说世界观创作的「伪论文」。目前已搭建项目目录和文档模板，供后续研究使用。

- [研究总索引](INDEX.md) 按学科和研究方向浏览课题。
- [研究文档模板](docs/templates/README.md) 提供课题说明、研究计划、实验记录和论文提纲。
- [素数剩余类几何实验室](Mathematics/Number-Theory/Prime-Residue-Geometry-Lab/README.md) 是数学 → 数论下的首个课题，目前为目录占位。

## English

This GitHub repository serves as a collection of materials for various papers—including my own conjectures and deductions regarding related concepts, explorations facilitated by AI tools, and even a few "pseudo-papers" centered on the world-building of my novels.

The repository currently provides a directory structure and document templates for future projects.

- [Research index](INDEX.md) lists projects by discipline and research area.
- [Research document templates](docs/templates/README.md) cover project overviews, research plans, experiment logs, and paper outlines.
- [Prime Residue Geometry Lab](Mathematics/Number-Theory/Prime-Residue-Geometry-Lab/README.md) is the first project under Mathematics → Number Theory and currently contains placeholders.

## 目录约定 / Directory convention

按 `学科/研究方向/课题` 新建目录，并在[研究总索引](INDEX.md)登记。
Add each project under `Discipline/Research-Area/Project` and register it in the [research index](INDEX.md).
